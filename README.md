# 🤖 Vega Firmware Repository

[![Firmware Hub](https://img.shields.io/badge/Live-Firmware%20Hub-blue)](https://firmware.dexmate.ai/)
[![GitHub Releases](https://img.shields.io/badge/Download-GitHub%20Releases-green)](https://github.com/dexmate-ai/vega-firmware/releases)

This repository hosts firmware releases for Dexmate's Vega robots.

## 🎯 Overview

The Vega Firmware Repository provides a centralized distribution system for Dexmate robot firmware. All firmware versions are hosted as GitHub releases with comprehensive metadata support.


## 🌐 Access Firmware

### Via Web Interface

Visit our [Firmware Hub](https://firmware.dexmate.ai/) for the best experience:

1. Browse available firmware versions
2. View detailed changelogs and compatibility info
3. One-click download of firmware packages

### Via GitHub Releases

For direct access, visit the [Releases page](https://github.com/dexmate-ai/vega-firmware/releases):

- `firmware_vX.X.X.dexmate` - Firmware package
- `metadata_vX.X.X.json` - Package metadata

## 📦 Firmware Package Format

Each `.dexmate` file contains:
- Firmware binaries for robot components
- Manifest with version and compatibility information
- Robot model compatibility data
